THE THINKING CHALLENGE
Bonus 1 — The Big Book of 100,000 Whys for Adults
==================================================

WHAT THIS IS
An interactive quiz web app with 48 comprehension questions
across the 12 domains of the book (4 questions per domain).

HOW TO USE IT
1. Open the file "index.html" in any web browser
   (Chrome, Safari, Firefox, Edge). Just double-click it.
2. No internet connection is required to run the quiz,
   except to load the fonts (it will still work offline,
   just with default fonts).
3. Nothing to install. It is a single self-contained file.

HOW TO PUBLISH IT ONLINE (so readers can scan a QR code)
You can host this for free on any of these:
  - Netlify (drag the folder onto netlify.com/drop)
  - GitHub Pages
  - Vercel
  - Cloudflare Pages
Once it has a public URL, generate a QR code pointing to
that URL and place it on the bonus page of your book.

FILES
  index.html   →  the complete quiz (open this one)
  README.txt   →  this file

NOTES
- The quiz works on phones, tablets, and computers.
- Scores for individual sections are remembered while the
  page is open. Closing the page resets them.
- To edit questions, open index.html in a text editor and
  find the "QUESTIONS" section in the script.
